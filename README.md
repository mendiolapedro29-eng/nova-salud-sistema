# Sistema de Inventario y Ventas - Botica Nova Salud

Este proyecto es una aplicación web Fullstack desarrollada para resolver el caso práctico de la gestión de inventarios de la botica "Nova Salud".

## Tecnologías utilizadas
* **Frontend:** React, Vite, Tailwind CSS, Axios, Lucide React.
* **Backend:** Node.js, Express, CORS.

## Características principales
* Login de acceso.
* Panel de estadísticas en tiempo real (Dashboard).
* Gestión de inventario (CRUD de productos).
* Punto de venta rápido con descuento automático de stock.
* Módulo de alertas de stock bajo y reposición.
* Historial de ventas detallado.

## Cómo ejecutar el proyecto localmente
1. Clonar el repositorio.
2. En la carpeta `backend`: ejecutar `npm install` y luego `npm start`.
3. En la carpeta `frontend`: ejecutar `npm install` y luego `npm run dev`.
